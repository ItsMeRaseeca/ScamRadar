# ScamRadar Demo - Quick Reference Card

## ⚡ 30-Second Setup
```bash
# Terminal 1: Backend
cd "scamradar_backend"
$env:GOOGLE_API_KEY = "YOUR_KEY"
python -m scamradar_backend.main

# Terminal 2: Frontend  
npm run dev
```
